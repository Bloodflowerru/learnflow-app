## 5. Известные баги / особенности

1. **`ActivityChart` в `AdminDashboards.tsx`** — сейчас **исправлен** (height в пикселях, а не `%`). Если в новой сессии график снова плоский — см. раздел «Фиксы».
2. **BlockNote `toSpec()`** — обязательная обёртка. В схеме должно быть `callout: toSpec('Callout', CalloutBlock)` — не просто `callout: CalloutBlock`. Иначе `Cannot read properties of undefined (reading 'layoutOnly')`.
3. **`custom-blocks.tsx`** — дубли импортов ломают сборку. Вверху должны быть только 3 строки:
   ```tsx
   import { createReactBlockSpec } from '@blocknote/react';
   import { useState } from 'react';
   import { fileToDataUrl } from './file-to-data-url';
   ```
4. **`Login.tsx`** — редирект по роли обязателен, иначе superadmin попадает на `/admin` и получает 400 «Не указана компания».
5. **`AdminHome`** — должна быть защита:
   ```tsx
   if (user.role === 'learner') return <Navigate to="/learner" replace />;
   if (user.role === 'superadmin') return <Navigate to="/superadmin" replace />;
   ```
6. **`/register`** — удалён из `App.tsx`. Публичная регистрация закрыта. Восстановить нельзя (по решению).
7. **JWT_SECRET** меняется при перезапуске бэкенда (dev). Токены инвалидируются, юзер выкидывается на `/login`. Решение: очистить `localStorage` → перелогиниться.
8. **`custom-blocks.tsx` должен содержать все 6 блоков.** Если после правок пропал `StyledSectionBlock` — новые секции не добавятся, будет ошибка `[schema] StyledSection: type=undefined`.

## 6. Фиксы на случай, если что-то сломалось

### График активности плоский
Файл: `src/components/AdminDashboards.tsx`, функция `ActivityChart`.
Должны быть константы:
```tsx
const CHART_HEIGHT = 140;
const MIN_VISIBLE_PX = 6;
```
И в рендере столбика:
```tsx
const heightPx = total === 0 ? 2 : Math.max(MIN_VISIBLE_PX, Math.round((total / max) * CHART_HEIGHT));
<div style={{ height: heightPx + 'px', ... }} />
```
**Не `%`, а `px`.**

### Ошибка `reading 'layoutOnly'`
Файл: `LongreadEditor.tsx` / `Read.tsx`.
```tsx
// ❌ неправильно
callout: CalloutBlock,

// ✅ правильно
callout: toSpec('Callout', CalloutBlock),
```
И `toSpec`:
```tsx
function toSpec(name: string, x: unknown): never {
  const result = typeof x === 'function' ? (x as () => unknown)() : x;
  return result as never;
}
```

### Superadmin попадает на /admin (400 «Не указана компания»)
- В `Login.tsx`: `if (user.role === 'superadmin') navigate('/superadmin')`
- В `AdminHome.tsx`: `if (user.role === 'superadmin') return <Navigate to="/superadmin" replace />;`

### Дубли импортов в custom-blocks.tsx
Проверить: `(Select-String -Path src\lib\custom-blocks.tsx -Pattern "import.*createReactBlockSpec").Count` → должно быть **1**.

### Vite отдаёт старый бандл
```powershell
Remove-Item -Recurse -Force node_modules\.vite -ErrorAction SilentlyContinue
npm run dev
```
